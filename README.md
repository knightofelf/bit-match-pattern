// 매칭비트 패턴 계산기 (범위 지정)
"숫자 \(n\)의 최하위 비트 위치로 매칭 크기를 정하고, 비트 길이와 이진 분할 경로로 재귀적 대칭 위치를 결정한다."

// 매칭비트 + 재귀 단계 + 경로 → 숫자
"재귀 단계로 시작 숫자의 기준 크기(\(2^{L-1}\))를 정한 뒤, '우' 경로를 1로, '좌' 경로를 0으로 이진수처럼 누적 연산하여 최종 숫자를 찾아낸다."
